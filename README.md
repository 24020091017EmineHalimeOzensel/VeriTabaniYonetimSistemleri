# Veri Tabanı Yönetim Sistemleri - Ödev Takip Deposu

Merhaba! Ben Emine Halime Özensel, yazılım mühendisi adayıyım. Bu depo, üniversite eğitimim süresince aldığım Veri Tabanı Yönetim Sistemleri dersi kapsamında hazırladığım haftalık projeleri ve laboratuvar çalışmalarımı içermektedir.

---

## Dersin Amacı ve Bana Kattıkları

Bu ders süresince yalnızca kod yazmayı değil, verinin mimarisini tasarlamayı da öğreniyorum. Bu süreçte kazandığım temel yetkinlikler:

* **Veri Modelleme:** İlişkisel veritabanı mantığını anlamak ve tablolar arası ilişkileri kurgulama yeteneği.
* **SQL Yetkinliği:** Karmaşık sorgular yazma, veritabanı yönetimi ve optimizasyon süreçlerini analiz etme.
* **Uygulama Entegrasyonu:** Geliştirilen Java uygulamalarını bir veritabanı ile konuşturarak uçtan uca sistemler inşa etme.

---

## Kullanılan Teknolojiler ve Araçlar

Projelerimi geliştirirken endüstri standardı olan şu araç ve teknolojilerden yararlanıyorum:

* **Programlama Dilleri:** Java
* **Geliştirme Ortamı (IDE):** IntelliJ IDEA
* **Versiyon Kontrol:** Git & GitHub
* **İşletim Sistemi:** Kali Linux (Güvenlik ve laboratuvar çalışmaları için)
* **Bağımlılık ve Arayüz Yönetimi:** JavaFX & Maven
